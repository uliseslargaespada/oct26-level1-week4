# GitHub profile README

Use GitHub in your browser this week. Your profile README introduces your learning focus. Keep your JavaScript exercises in your class folder or private approved workspace. Local Git commands begin in Week 5.

1. Sign in to your existing GitHub account or create your own through [GitHub](https://github.com/) if needed. Verify the account when prompted. Never share the login, email verification codes, or recovery information in class.
2. Open your profile and note the exact account **username**, not the display name. If a profile README exists, improve it in place.
3. Otherwise, use [New repository](https://github.com/new). Under your personal account, name the repository exactly the same as your username. GitHub requires that repository to be public with a non-empty root `README.md` for it to appear on a regular profile. Initialize with a README if the option is offered. A managed user account may not support this feature; ask your instructor how to submit a Markdown draft instead.
4. Open `README.md` in that repository and use its web editor. Draft short sections: a public-friendly name, what you are learning, and one skill you are practicing. Use Markdown headings and bullets. Use the preview before saving.
5. Save using the web editor's commit action. A commit here records the web edit to this file; the terminal Git workflow comes next week. Open your profile page and check that the updated section shows. It is public; only include information you want strangers to see.

Example structure to adapt:

```markdown
# Hi, I'm Alex

## What I'm learning
- HTML and CSS
- JavaScript fundamentals

## Current practice
I'm using small scripts to trace decisions and test edge cases.
```

Do not include a phone number, personal address, class attendance, passwords, private links, or classroom scripts. If public publication is unsuitable or unavailable, retain a local `PROFILE-DRAFT.md` and arrange approved evidence with the instructor. Save only your own content; there is no need to make other repositories public.

Official reference: [GitHub: Managing your profile README](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme).
